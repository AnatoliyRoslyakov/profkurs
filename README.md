# Профкурс

[Открыть сайт](https://anatoliyroslyakov.github.io/profkurs/)

Шесть коротких шагов помогают выбрать направление для пробы. Участник отмечает интересы и навыки, формат работы, доступное время, желаемую сложность и глубину погружения. Текущая профессия и возрастная группа добровольны. Результат — одна профессия, причина выбора и первое практическое задание.

## Подключить к Telegram

1. В [@BotFather](https://t.me/BotFather) создайте бота командой `/newbot` или выберите своего через `/mybots`.
2. В настройках бота откройте **Bot Settings → Configure Mini App** (или **Main Mini App**), включите основное приложение и укажите `https://anatoliyroslyakov.github.io/profkurs/`. Кнопка запуска появится в профиле. Для кнопки рядом с полем сообщения отправьте BotFather команду `/setmenubutton`, укажите ту же ссылку и подпись «Профкурс».
3. Откройте профиль своего бота и нажмите **Запустить приложение**. Ссылку для участников можно составить по образцу `https://t.me/имя_бота?startapp`. [Настройка Mini Apps в Telegram](https://core.telegram.org/bots/webapps#launching-the-main-mini-app)

### Интерактивная карточка внутри сообщения

Карточка задаёт два вопроса прямо в личном чате. Она передаёт ответы в Mini App, где можно вписать свою профессию, закончить анкету и получить результат. Виджет запускает приложение ссылкой `?startapp=route1_S_I`; S и I — индексы статуса и интереса. Формат содержит только эти два выбора.

Для разовой отправки карточки скачайте репозиторий, установите Node.js 18+ и откройте терминал в папке проекта. Получатель должен сначала нажать «Старт» в личном чате с вашим ботом. Задайте `TELEGRAM_BOT_TOKEN` в окружении. В macOS с zsh его можно ввести скрыто:

```sh
read -rs 'TELEGRAM_BOT_TOKEN?Токен бота: '
export TELEGRAM_BOT_TOKEN
node telegram/send-widget.mjs ЧИСЛОВОЙ_ID_ЧАТА
unset TELEGRAM_BOT_TOKEN
```

Запуск из меню работает для всех посетителей без этой команды. При автоматизации отправки в существующем боте используйте тот же шаблон и метод `sendWidget` в ответ на `/start`. [Telegram Widgets](https://core.telegram.org/bots/widgets)

## Как устроен подбор

У O*NET Interest Profiler мы взяли идею выбирать любимые занятия из разных типов работы. У National Careers Service — отдельный вопрос о том, что человеку хорошо удаётся. Наш короткий опрос добавляет практические ограничения на обучение. Он даёт направление для пробы. [O*NET](https://www.onetcenter.org/IP.html) · [National Careers Service](https://nationalcareers.service.gov.uk/discover-your-skills-and-careers)

GitHub Pages публикует содержимое `docs/` из ветки `main`. Браузер отправляет анкету на единственную серверную функцию, чей HTTPS-адрес указан в `docs/config.js`. Функция проверяет поля, обращается к DeepSeek и проверяет структуру ответа. Ключ есть только в секретах функции. [Контракты, лимиты и настройки сервиса](api/CONTRACT.md)
