# Профкурс

[Открыть сайт](https://anatoliyroslyakov.github.io/profkurs/)

Шесть коротких шагов помогают выбрать направление для пробы. Участник отмечает занятия из разных сфер, выбирает место и атмосферу работы, указывает навыки, доступное время, сложность и глубину погружения. Можно добавить своё увлечение. Текущая профессия и возрастная группа добровольны. В результате открываются три профессии. У каждой есть специализации, пример рабочего дня и совет для знакомства с направлением. Отдельный текст показывает, как совместить интересы.

## Карточка в Telegram

После подключения [@prof0bot](https://t.me/prof0bot) отвечает на `/start` и `/profkurs` интерактивным сообщением. В личном чате участник проходит анкету кнопками. В том же сообщении появляются три профессии, специализации, примеры рабочего дня и ориентиры для начала. «Пройти заново» очищает предыдущую подборку.

Владельцу нужна персональная ссылка подключения из чата с разработчиком. В [@BotFather](https://t.me/BotFather) откройте `/mybots` → `@prof0bot` → **API Token** и введите действующий токен на странице настройки своего «Профкурса». Она проверит бота и подключит обработчик. При наличии другого webhook появится предупреждение. Затем откройте личный чат с ботом и нажмите «Старт». Прохождение карточки обходится без Main Mini App. [Telegram Widgets](https://core.telegram.org/bots/widgets)

Для сборки Worker выполните `node telegram/build-service.mjs ПУТЬ_К_WORKER.js`. Без аргумента команда проверяет лимиты размера. Нужны привязка R2 `CARD_DATA`, постоянный секрет `TELEGRAM_CARD_SECRET` и настройки основного API. Токен бота хранится зашифрованным; ответ модели привязан к сообщению. Ранее отправленные карточки сохраняют прежний HTML. Команда /start отправляет новую версию.

## Как устроен подбор

У O*NET Interest Profiler мы взяли идею выбирать любимые занятия из разных типов работы. У National Careers Service — отдельный вопрос о том, что человеку хорошо удаётся. Наш короткий опрос добавляет практические ограничения на обучение. Он даёт направление для пробы. [O*NET](https://www.onetcenter.org/IP.html) · [National Careers Service](https://nationalcareers.service.gov.uk/discover-your-skills-and-careers)

GitHub Pages публикует содержимое `docs/` из ветки `main`. Браузер отправляет анкету на единственную серверную функцию, чей HTTPS-адрес указан в `docs/config.js`. Функция проверяет поля, обращается к DeepSeek и проверяет структуру ответа. Ключ есть только в секретах функции. [Контракты, лимиты и настройки сервиса](api/CONTRACT.md)
